# UI 重构规格（精简执行版）

目标：信息架构与视觉整体对齐参考 App；不再局部修补。

## 1. 底栏（Material 与 Miuix 都必须有）
- 左：主页/概览
- 右：设置
- 中间：按项目功能设 2 个操作项（建议：门锁、开门/打卡）。文案图标由实现者结合项目定。
- Miuix 用官方 NavigationBar；Material 用等价的 NavigationBar（不是只做按钮）。

## 2. 主页/概览页
- 左上：大标题（App 名）。
- 第一栏：状态 banner，展示账号登录状态 / 当前门锁连接状态；点击跳转登录或开锁页（类比 KernelSU/LSPosed 激活 banner）。
- 下方：信息卡（当前门锁、账号、最近状态等必要信息）。
- 禁止在主页写“当前界面风格”。

## 3. 设置页
- 分组卡片：主题设置（深色/动态取色/种子色/调色板风格）、门锁与打卡偏好、其它。
- 底部一个 banner → 关于页。
- 二级菜单/选择菜单对齐参考图（用 Switch/Arrow/Dropdown 风格，不要自造大圆角整块）。

## 4. 优先级与入口
- 扫码导入、手动导入 = 后备入口，放在“门锁”页/二级菜单，不占整页。
- 功能操作放功能页；偏好放设置；低频放二级菜单。

## 5. 组件与视觉
- 搜索框用胶囊；非搜索元素不要过度圆角。
- 开关/状态要有 ✓/×。
- 回弹动画正确（可用 Miuix 默认 / spring）。
- Material 与 Miuix 按钮风格分开，不要统一成 Miuix。
- Miuix 动态取色（Monet）必须可用。
- 图标使用率对齐参考 App（底栏、设置项、状态）。

## 6. 动画
- 页面切换动画保留现有（已认可）。
- 补充开关/按钮按压与回弹。

## 7. 验收
- assembleDebug 通过。
- 后端功能（登录/门锁/二维码/打卡/开门密码）不回归。
